08Autonomous navigation

No GPS in the loop. A heading, a grid, a repeatable stop.

Navigation is relative and local. The rover follows a predefined grid using inertial feedback, which keeps it working under canopy, between rows and anywhere a satellite fix is unreliable. GPS, when fitted, is for logging — not for steering.

01

Serpentine grid traversal

The mission is a fixed sequence of cells. The rover crosses each row, turns at the headland, shifts one row and returns — no path planning is improvised in the field.

02

Closed-loop 90° turns

Every turn is measured, not timed. The IMU reports actual rotation and the controller stops when the heading target is reached.

03

IMU heading reference

The BNO085 provides orientation continuously, so the rover knows its heading without satellite positioning.

04

PD drift correction

Heading error and its rate drive a proportional-derivative correction, clamped so a large error cannot command an aggressive motor spike.

05

Active reverse-pulse braking

Instead of coasting into the next cell, drive is briefly reversed to arrest momentum, improving repeatability of the stop position.

Headland turn sequence

Backup → Turn → Shift column → Turn

Reversing clear of the row before turning keeps the probe and chassis away from crop rows, and makes the entry into the next row repeatable rather than approximate.

09Live farmer dashboard

The field, as the rover reports it.

During a mission the ESP32 publishes soil readings, position in the grid and sprayer state to Blynk. The farmer sees the same measurements the rover is deciding on — not a summary written afterwards.
